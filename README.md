# MSR Admin

A modern and scalable Admin Panel built with **Laravel 13**, designed to manage users, roles, permissions, settings, and other dynamic application features.

---

## Features

### Admin Panel

- Admin authentication
- Dashboard
- User management
- User details
- Role management
- Permission management
- Profile management
- Application settings
- Secure admin routes
- Responsive admin interface

### Roles & Permissions

The application includes role-based access control to manage administrator permissions.

- Create and manage roles
- Create and manage permissions
- Assign permissions to roles
- Assign roles to users
- Restrict access to protected admin features
- Middleware-based authorization

### Search & Dynamic Features

- Dynamic data searching
- Server-side filtering
- Pagination
- Dynamic sorting
- Search by multiple fields
- AJAX-based dynamic operations where applicable
- Reusable query/filter logic

### Database & Seeders

- Laravel migrations
- Database seeders
- Factory support
- Default admin/user seeding
- Role and permission seeding
- Application configuration seeding

### Security

- Laravel authentication
- Password hashing
- CSRF protection
- Authentication middleware
- Authorization middleware
- Form request validation
- Mass-assignment protection
- Secure session handling
